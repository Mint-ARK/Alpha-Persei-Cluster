2. **选区 / 选档断连卡死修复**：
   - 修复在选区或选档界面切换时的断连卡死问题（此前触发后往往需要退出 SDK 登录并重新发起登录才能恢复）。

3. **新增四档抽卡概率模型（原默认 + 3 套新模型）**：
   - **0 号模型**：原默认模型（现行基线）。
   - **1 号模型**：在 0 号模型基础上改进保底规则——修复了 90 池首金必中 UP 的问题，贴合官方说明。
   - **2 号模型**：校对主模型（查表模型），按基础出金率与综合目标反算生成软保底概率表；考虑到随机种子（seed）波动，默认包含 **+0.005 个百分点** 补正，确保综合概率在绝大多数情况下持平或高于 **2.40%**。
   - **3 号模型**：特殊影子模型（反馈模型），借鉴**反馈电路**思想设计（“欧了往回拽，非了往前拉”的欧非平衡机制）；存在特殊补正值 `100`，该偏移直接反映到最终单抽出金概率，补正到 `100` 时必定出金（可在 Web 面板调整），并具备**冷启动过冲与大参量稀释保护**。

   #### 四个模型的概率对比

   | 卡池 | 0 号现行 | 1 号只修保底 | 2 号查表 | 3 号反馈 |
   | --- | ---: | ---: | ---: | ---: |
   | 70 抽扩充／常规／钥从 | 2.411% | 2.411% | 2.398% | **2.405%** |
   | 90 抽锚定修正档 | 2.162% | 2.989% | 2.396% | **2.409%** |
   | 90 抽锚定旧规则档 | 2.162% | — | 2.398% | **2.411%** |

   > **注**：以上数值由 4 个不同随机种子输入测试、共计测试 **400 万抽**，经蒙特卡洛算法验证，所有模型在大样本量下均依概率收敛至指定目标值（`0.024`）。需要注意的是，即便3号模型在偏移值为0的情况下，其基准概率也略微高于其他模型，若将该模型出率拉回0.024，需要对其施加负偏移，也就是增强负反馈回路的效果，往后拽的（负反馈）比往前拉（正反馈）的多。负偏移下虽然基准概率保护到0.016，但是其在70抽卡池测试探针的表现中，硬吃第70抽才出金卡的概率由2号模型基准的3%-4%飙升至10%-30%，0偏移下回落到约10%左右，因此这个模型的末端曲线在负偏时的“手感”表现不佳。

   #### 2 号模型的算法与面板参数说明

   2 号模型在面板上提供三个参数输入（对应 [面板输入 (`Gacha.tsx`)](v5_server/web_src/src/panels/Gacha.tsx#L223)），默认填写 `1.6`、`2.4`、`0.005` 即可（前两项单位为百分数 `%`，第三项单位为百分点），系统会据此自动反算软保底曲线，无需手动填写每一抽的概率：

   | 输入框 | 默认值 | 它控制什么 |
   | --- | --- | --- |
   | 主表基础出金率 | `1.6` | 进入软保底前，每抽出任意 S／五星的概率是 `1.60%` |
   | 主表综合目标 | `2.4` | 把软保底和硬保底算进去后，长期出金率要达到的目标 |
   | 主表补正 | `0.005` | 加到综合目标上，最终按 `2.405%` 拟合 |

   补正加在长期目标上，因此前段每抽仍保持 `1.60%`；若将补正填为 `0`，则会按 `2.400%` 重新拟合。

   * **软保底拟合方式**（详见 [拟合公式 (`draw_models.py`)](v5_server/draw_models.py#L74-L99)）：
     以 70 池为例，前 65 抽固定为 `1.60%`，第 70 抽必出；中间第 $k$ 抽（$66 \sim 69$）按以下公式计算：

     $$\text{第 } k \text{ 抽出金率} = 1.60\% + (100\% - 1.60\%)\left(\frac{k - 65}{70 - 65}\right)^\gamma$$

     其中分数项表示当前步入软保底区间的进度；$\gamma$ 越大，前几抽增幅越平缓、出率越集中在末尾。程序反复调整 $\gamma$，直至整张表计算出的长期出率等于目标值。使用默认参数时，第 66、67、68、69 抽已垫到该抽时的单抽出金率分别为 **`13.60%`、`31.30%`、`52.06%`、`75.10%`**。

   * **90 池规则与参数边界**（详见 [90 池规则与拟合入口 (`draw_models.py`)](v5_server/draw_models.py#L56-L64)）：
     90 池默认从第 81 抽开始进入软保底；校准时歪出的 S 也会计入综合出金率，只有拿到指定 UP 才结束这一轮保底。勾选面板「**90 池出金即 UP**」后，程序会按旧规则重新拟合，软保底改从第 66 抽开始。

   * **实用输入边界**：当基础出金率填 `1.60%` 时，由于 70 池的起点和硬保底固定，所有卡池共用的「综合目标 + 补正」大致只能落在 **`2.3645%～2.4423%`** 区间内。例如想略微提高出金率，可将综合目标填为 `2.42`、补正保留 `0.005`（实际按 `2.425%` 拟合）；若直接填 `3` 等超出边界的值，该基础率下会提示超出可达范围。
