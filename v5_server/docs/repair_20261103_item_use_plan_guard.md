## 修复

- 整包先生成使用计划，再检查总余额并执行。计划选择与执行使用同一个mode，避免“检查一种分支、实际执行另一分支”。任何非法条目都会在cost_item、随机抽取、状态效果之前拒绝，不能先扣前面的合法物品。
- 自选索引按1-based逐个核验范围，选中内容必须是正整数ID或有效奖励对。明确越界不再只写warning后报成功；执行阶段的越界防线也改成失败。保留原有缺省第一项，不把本票扩展为A55多选/重复选择资格修复。
- 缺少使用配置、无法执行的参数形状、损坏奖励对、缺随机池、损坏概率/权重结构均返回2并保留物品。奖励结构检查不等于认证所有特殊礼包的完整玩法语义；未支持的参数明确拒绝，不能继续空扣。例如现有20013的404单参链接目前没有对应效果实现，因此拒绝使用并保留库存，未在本轮补造其功能。
- 生日/永久放映道具保留已有免消耗路径。黑区信标41101是明确注册的状态效果，可没有usable配置但必须有可调用处理器；处理器异常或明确返回False时回滚，不再吞错报成功。
- 表情激活使用已注册的item→emoji映射，允许成功时没有drop_list；不能把“空掉落”作为统一失败条件。真实随机未命中同样允许正常消耗，A56概率和base/weight处理保持。

不修改真实存档、不做历史补偿；A55、其他特殊多选/福袋实例协议和未实现状态玩法仍待其各自任务，不把所有use_list限制为单选。未知配置的语义不靠猜测补成免费奖励。
