## 修复

- A42：普通和一键突破共用严格的阶段配置/费用模板读取。缺少模板、缺少阶段费用索引、损坏JSON等均拒绝，不再以1001加阶段猜测费用，更不把缺配置当免费。模板明确配置空列表或零数量费用仍可按免费规则处理。
- A43：一键请求先计算当前累计经验、本次合法投入、目标等级与所有阶段的经验前置。每次突破都必须达到该阶段的等级上限；合法的“本次投入补满后突破”和连续多阶保留，不能只校验请求开始时是否满级。
- 在执行前汇总经验材料、各阶段费用和强化金币，检查完整余额。方案全部通过后才扣费、消耗素材刻印、返还多余经验材料、保存最终经验与突破阶段。保留原有经验价值、金币比例和material_give_back返还方式。
- 请求突破次数不能被静默截断，以免Lua按原请求次数增加阶段。配置里的零突破上限按0处理，不再通过默认值变成4。受保护、重复或包含目标自身的素材刻印不参与方案。
- 两个服务入口用保存点事务保护直接调用；失败回滚库存、阶段、素材实例及上下文差量/删除通知，之后可重试。

未改普通强化、继承、价格数值、通用回执事务规则及全部事件消费者。费用与阶段的静态配置仍来自存档，未自动修真实库中的缺配置。
