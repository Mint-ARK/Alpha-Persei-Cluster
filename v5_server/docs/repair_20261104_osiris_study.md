## 沙盘计分

原生GameSetting可确认基础分800000、基准时间120000、系数5，但未找到完整官方计分过程。采用用户已授权的奖励门槛私服方案，明确标记为 **private_time_bonus_v1**：

`800000 + max(0, 120000 - 战斗毫秒数) × 5`

60秒为110万分，100秒为90万分，120秒及以上为80万分。缺失／零耗时只给基础分，不伪造最快表现；失败与退出不保存通关或得分。不声称这是官方原公式。

## 积分、领奖与登录

18档常驻积分奖励依据已完成的学习记录数，单关重打和六个沙盘不增加该计数。68171冷快照从合法关卡事实导出六个已完成章节，过滤未知ID及无关旧标记，避免Lua用未知关卡索引配置。

专用领奖页读取60201：`ActivityAccumulativeAction` 将其交给 `OsirisPlayGameData.InitActivityPointData`；通用60105仅更新 `ActivityPointData`，不能替代这个缓存。因此在线学习积分变化发送一条活动323801的60201，以及只有该活动一行的60105。60201包含本活动至多18个已领ID，不全推其他活动。

登录读取抓包所属活动，只替换323801的60201，保留其他活动的同协议帧；缺帧时补一条当前账号数据，移除旧账号旧积分／已领状态。只读核对account.db中原捕获seq137的60201属于323801，seq145属于3639701；没有修改该库。68171也强制动态和缺帧补入，生成失败不退回静态抓包。

领取成功后原生Osiris回调会标记自己的已领缓存，另用60107只同步本次新领的Osiris ID到共用缓存；不发全量历史。资源仍走17023。28007任务差量、68173／75／77、60105／60201和54033均在提交前编码，任一必要帧失败时SQL、extra、通知与成功br一起回滚，同场可重试。
