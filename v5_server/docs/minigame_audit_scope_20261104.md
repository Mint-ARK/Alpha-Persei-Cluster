## 审查顺序

1. 先复核诡谈夜话“任务页返回 Lua 异常”的既有反馈，日志位于 `archive/activity_catalog_fix_20261025_131213/rogue_task_exit_client.log`。当前只登记待复现，不视为已修复。
2. 对当前常驻入口逐项检查初始化、操作、结算、领奖、重登恢复，优先积分领奖、音乐奖励、弹珠技能和赛事完成，再检查委托生命周期及经营存档。
3. 对无业务入口的候选逐一核对 Lua、版本和活动配置，区分旧入口、本地结算、禁用及真正未完成；确认后才新增编号缺陷和实现票。

每个玩法按同一条链记录证据：`活动/版本入口 → 初始推送 → 合法请求 → 状态转移 → 持久进度 → 奖励幂等 → 原子差量及客户端回调 → 重登恢复`。钥从/刻印实例按实例生命周期处理；不把普通材料全量代替必要实例更新。
