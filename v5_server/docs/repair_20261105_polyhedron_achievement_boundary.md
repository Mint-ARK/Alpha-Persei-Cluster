# 多维变量与虚构推演成就来源隔离

2026-11-05，仅本地源码，未操作真实存档、服务、云端或Git。

原 `achievement_service` 将多维变量的 `POLYHEDRON_PASS` 及 `polyhedron_*` 解锁表用于条件300005、300006、300009、300012、300013、300014。这些条件在当前原生 `decompiled_v2/x64/game/config/achievementcfg.lua:11606` 起及导出配置中属于“虚构推演：寻屿勘云记”。其中终端不等于推演结局、信标不等于战术指令、可招募角色不等于外接程序。只增加通关布尔守卫仍会混淆两个玩法。

已撤下这两条错误生产来源。多维变量结算仍通过原事件推进条件423的参与任务；已保存的成就进度、完成时间和领奖记录保留，不追扣资产。虚构推演的真实成就事实生产需要单独接入对应玩法，不将本轮隔离当作全部成就链修复。

`tools/verify_polyhedron_achievement_boundary.py` 三项内存AccountDB和真实codec检查通过：大量多维解锁不能自愈推演成就；通关与放弃保留参与任务但不产生推演成就；旧已领记录与余额保持不变。覆盖前副本位于 `archive/polyhedron_review_20261105/before_achievement/`。未经游戏实测。
