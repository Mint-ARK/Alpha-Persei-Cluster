## 原生依据与范围

只读来源是备份客户端StreamingAssets中的bundle `d2523a220497431f722433745600837a.ys`，文件97848字节、UnityFS头偏移12。原始地图TextAssets与来源证据保存在 `archive/summer_board_movement_20261105/native_maps/`。本轮不改客户端或其资源。

`ChessBoardHeroEntity.MoveToPos` 明确区分updatable自动格和普通格：前者只改位置和状态，后者处理离开／进入、扣预算、停留和Buff。`OnHeroTurnEnd` 更新Buff后将状态改为TURN_START；NPC阶段结束才推进地图回合。当前85014仅在无NPC时执行这条完整回合路径，不伪造空NPC路线来跳过实际NPC。

实际首张地图5,7存在禁行，不能从这里直接走到5,6；原生引导指向6,8的机会格。专项首版误把5,6当合法分支，按原始banDir纠正夹具；事件与引导换档改在6,6→5,6这条合法相邻路径的内存状态下验证，未把它称为自然完成开荒引导。

地图当前有158处不同事件池引用，其中501113不在当前读取的Lua事件表中。遇到缺失或未接通事件时，在回包前返回失败并回滚，不猜事件参数或让客户端索引空配置。

本轮校验原生地块walkable、六方向和出格禁行，不推测C#路径中的掉头优先级或物件fix_walkable的细节，也未实现NPC路径生成。完整可玩验收仍待后续链路。
