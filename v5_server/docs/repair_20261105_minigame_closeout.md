## 共用领奖失败边界

专项注入发现普通TaskSubmitOp/TaskOneKeySubmitOp的ACK编码失败会用空成功回执回退，资产差量也原为容错生成。两类操作现将必要ACK/strict资产差量在事务内准备，生成失败回滚资产、领取标记与台账。成功保17023→28011/28015，避免回包前资产未刷新。新档FreshTaskMixin亦按资产→ACK顺序，保原有新手快照，不新增全量活跃度帧；活跃度依旧由客户端领奖回调本地增量。
