## 统计口径与恢复

只有通过当前对局校验的通关或中断才累加一次本局统计，普通保存、继续、回滚点写入不统计。中断采用当前保存的结算摘要，挑战中断不会增加通关次数；已经完成的帖子重开一局可以继续累计操作。重复结束请求沿上一轮终态回执，不再次更新统计或推送差量。

统计与对局阶段保存在本库 `roguecard.runtime_v1.<uid>.statistics`，包含计数器、各牌组/难度成功次数及一次性历史任务基线。首次采用已有未领取任务的进度后，后续实际操作立即接着累计；保持更高的已有进度，不自动回退或猜测旧总次数。旧挑战最高难度不能推导通关次数，因此不据此伪造历史完成量。

新增 `rogue_card_progress.py` 负责统计和任务投影。只推进已在当前账号存在、未领奖、未过期的目标任务，尊重领取账本；复合参数严格解析，不能只匹配其中一个数字。已领取和损坏配置不被重新发奖或误推进。

新增必需事件 `ROGUE_CARD_PROGRESS`，由 `task_listener` 订阅；`EventBus.emit_required` 只供需要随外层事务失败的参与者使用，原 `emit` 的异常隔离行为保持。计数、对局结束、任务更新和28007构包同事务，监听器或必要差量失败会回滚，调用体异常不重复执行。正常操作只补任务差量，不新增任务全量。

普通 `gen_28001` 和新档任务快照在读取列表前，从持久统计恢复后建/漏记的任务，登录仍只使用原本的任务快照，不额外广播一次全量。恢复函数幂等。
