# 第164轮｜总览、公共在线状态与读口恢复

扫描日期：2026-10-15。问题编号：A359、A360、A361、A362。

## A359｜GM 总览使用固定在线人数和统计值，查询失败也显示正常

### 出现什么现象

面板总览把固定占位值显示成实际在线、累计时长和模块状态。

### 初步定位

Reader固定在线1、附加312000秒及多项就绪文案，SQL失败也被转换成空结果；前端请求前还显示本地样例。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `gm_reader.py` | 总览、query异常 |
| `serverContext.tsx` | 初始状态 |
| `Overview.tsx` | 展示 |

## A360｜GM 只读连接失败后退回可写连接，只读保护失效

### 出现什么现象

只读数据库连接建立失败时，会降级成可写连接。

### 初步定位

mode=ro失败后改普通sqlite连接，query_only设置失败也忽略并缓存；双重失败会失去只读保护，还可能在错误路径创建库。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `gm_reader.py` | _get_ro_conn |

## A361｜日志增量游标跳过截断和超额记录，面板漏显示日志

### 出现什么现象

日志新增超过200条时会漏行，服务重启或日志截短后游标也可能跳错。

### 初步定位

后端返回total但只截取limit条，前端直接把offset推进到total；代次变化仍沿用旧游标取得的结果，没有明确next_offset和重置合同。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `gm_reader.py` | get_server_logs |
| `Overview.tsx` | 日志增量与server_start_time |

## A362｜旧请求覆盖新状态，面板在线状态或版本显示回退

### 出现什么现象

旧状态请求会覆盖新请求结果，版本切换成功后也可能显示旧版本。

### 初步定位

公共状态和版本刷新完成时无条件提交，没有请求owner或在途合并；定时、手动刷新和明确切换之间缺少顺序保护。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `serverContext.tsx` | refreshStatus、refreshResVersion、switchVersion |
