# 第12轮｜技能升级上限与技能编号

扫描日期：2026-09-20。问题编号：A33、A34。

## A33｜技能升级被服务端截断，客户端仍按原次数加等级

### 出现什么现象

技能接近上限时一次请求升级多级，存档停在上限，客户端显示却继续增加。

### 初步定位

服务端把结果裁剪到技能上限，但成功回复没有带实际增量；客户端成功回调仍按原请求 num 累加，双方使用了不同增长值。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `hero_service.py` | upgrade_skill、enhance_skill_element |
| `heroaction.lua` | 技能升级成功回调 |
| `herodata.lua` | 技能等级累加 |

## A34｜未知技能编号可被直接写入并升级

### 出现什么现象

未知或不属于该角色的技能编号，也能被追加并升级。

### 初步定位

upgrade_skill 找不到技能编号时直接追加到列表，没有检查角色的技能配置；费用缺失又沿用默认值，使无效技能继续通过处理。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `hero_service.py` | upgrade_skill |
| `operations.py` | SkillUpOp |
