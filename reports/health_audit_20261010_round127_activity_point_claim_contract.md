# 第127轮｜通用活动积分领奖入口、资产反馈与日周恢复

扫描日期：2026-10-10。问题编号：A245、A246、A247。

## A245｜活动领奖入口覆盖配置，奖励内容和领取归属错误

### 出现什么现象

通用活动奖励被其他模块接管，发错奖励并记录到错误活动。

### 初步定位

60054存在新旧入口覆盖，后加载实现只识别38项，其他奖励用固定资产兜底并按ID除100推活动，没有读取通用配置归属。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `minigame_service.py` | 60054注册与奖励表 |
| `main.py` | 加载顺序 |
| `core.py` | 命令注册 |

## A246｜活动领奖未检查积分与奖励目录，零积分或未知编号也能领

### 出现什么现象

零积分、未知奖励和未开放活动也能领取活动奖励。

### 初步定位

当前60054实现只检查已领集合，没有核目录、积分门槛、玩法分值及活动资格；未知ID沿默认奖励继续入库。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `minigame_service.py` | 活动领奖资格与兜底 |

## A247｜活动奖励已入库却未刷新资产，客户端余额和物品不更新

### 出现什么现象

活动、累充和套装奖励已入库，在线资产余额却没有更新。

### 初步定位

资产层只登记 touched_items，相关回复没有调用通用资产刷新；奖励弹窗不会替代权威余额更新。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `minigame_service.py` | 活动领奖回复 |
| `operations.py` | 累充、套装与 _refresh_frames |
| `inventory_service.py` | 资产标记 |
