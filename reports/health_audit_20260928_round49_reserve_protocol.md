# 第49轮｜编队协议与回包

扫描日期：2026-09-28。问题编号：A73、A74。

## A73｜同名协议结构混用，编队保存与出战信息解析错误

### 出现什么现象

合法编队请求解析后没有角色，保存被跳过。

### 初步定位

运行时按无命名空间的消息名建立 schema 索引，把不同协议模块的同名嵌套结构混用，角色字段被按另一种结构解码。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `decode_schema.py` | 嵌套消息索引 |
| `middleware.py` | h_63006 |
| `reserve_codec.py` | 编队原始解析 |

## A74｜编队请求缺少客户端等待的回复，操作一直等待

### 出现什么现象

保存多队数据后，客户端等待的成功回调没有触发。

### 初步定位

客户端等待 63007，h_63006 却把请求当成无需回包的单向消息，保存后返回空帧列表。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `middleware.py` | h_63006 |
| `reserveaction.lua` | SaveMultiChessContData |
