# 第129轮｜新手任务、回归权益与月卡天数生产端

扫描日期：2026-10-13。问题编号：A256、A257、A258、A259、A260。

## A256｜已有一个新手任务就跳过补建，后续阶段任务缺失

### 出现什么现象

已有一条任务的账号，不会补建缺失的新手和回归任务。

### 初步定位

28001只在整个任务列表为空时初始化全部配置；其他补建只覆盖有限类型，升级等正常事件也不会创建这些缺行。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `generator.py` | gen_28001 |
| `task_listener.py` | 任务补建范围 |

## A257｜指定关卡任务监听错误事件，通关后条件 401 不推进

### 出现什么现象

指定主线关卡通关后，新手任务160139仍没有进度。

### 初步定位

任务条件401要求指定关卡，监听器却将其挂在怪物击杀并用 monster_id 匹配；普通和首次通关消费者均未处理该条件。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `task_listener.py` | 条件401、STAGE_PASS与MONSTER_KILL |

## A258｜回归任务已领奖但找回机会未保存，重新登录丢失权益

### 出现什么现象

领取回归任务后若资源找回请求中断，这次权益会丢失。

### 初步定位

60401任务先永久标已领，但没有持久化待消费找回次数；后续62016依赖页面临时回调，重建页面时既无次数也无可领奖任务。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `operations.py` | TaskSubmitOp与62016 |
| `regressionresretrieveview.lua` | 两步领取 |

## A259｜月卡累计签到天数没有生产，持续签到也不推进新手任务

### 出现什么现象

普通月卡已连续签到，新手月卡累计天数却一直为零。

### 初步定位

普通日奖只更新 sign 和 month_card，没有桥接 newbie_activity.mc_sign_times、mc_new_sign，恢复只读取未变化的累计字段。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `operations.py` | MonthCardBonusOp |
| `recharge_service.py` | 新手月卡累计 |

## A260｜月卡签到回包补入默认状态，在线已签到标记被覆盖

### 出现什么现象

领取月卡日奖后，新手月卡状态在线被清成未激活。

### 初步定位

操作没有生成真实59009，Core按骨架用schema默认零值补帧；客户端将该包更新到已初始化的新手充值状态。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `operations.py` | MonthCardBonusOp.respond |
| `core.py` | 默认补帧 |
| `skeleton.json` | 34024 |
| `activitynoobaction.lua` | 状态更新 |
