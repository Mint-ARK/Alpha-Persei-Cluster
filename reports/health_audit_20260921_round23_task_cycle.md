# 第23轮｜任务跨周期状态链

扫描日期：2026-09-21。问题编号：A50。

## A50｜补建任务缺少周期类型，已领状态跨日或跨周不清除

### 出现什么现象

补建的周期任务首次可领取，跨日或跨周后却一直保留已领状态。

### 初步定位

自动激活只写任务编号和进度，task_type 留为默认零；重置监听按实例的 task_type 过滤，漏掉这些任务。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `task_listener.py` | _trigger_task_condition |
| `timer_listeners.py` | 日常与周常重置 |
| `account_db.py` | task.task_type |
