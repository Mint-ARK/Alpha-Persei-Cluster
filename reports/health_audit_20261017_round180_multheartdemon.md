# 第180轮｜多重心魔独立纵向链

扫描日期：2026-10-17。问题编号：A377、A378、A379。

## A377｜多重心魔阶段编号错误，挑战期的开战按钮被挡住

### 出现什么现象

多重心魔活动开放时，客户端仍隐藏开战按钮。

### 初步定位

75017固定challenge_stage1，客户端约定0为挑战、1为排名处理、2为公示；正常开放条件下仍被投影到排名处理阶段。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `generator.py` | 75017 |
| `multheartdemonmainview.lua` | 阶段与开战入口 |

## A378｜多重心魔保存、重置和结算缺少处理，返回成功却无玩法状态

### 出现什么现象

多重心魔保存、重置等请求只收到成功确认，没有实际业务状态。

### 初步定位

75020、75022、75026、75028没有Operation或旧处理器，骨架只回成功；82类结算缺少75025专属状态，75017又固定空列表。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `middleware.py` | 骨架分发与82类结算 |
| `operations.py` | 心魔入口 |
| `generator.py` | 75017 |

## A379｜多重心魔奖励任务没有进度事件，正常游玩也不增长

### 出现什么现象

多重心魔普通奖励任务没有完成进度。

### 初步定位

四项type3007任务使用11006、11007、11008条件，现有任务监听和业务生产端没有推进这些条件；通用任务领奖本身不是专门750xx入口。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `task_listener.py` | 心魔条件生产 |
| `assignmentcfg.lua` | 40309001—40309004 |
| `rewarditem.lua` | 通用任务领奖 |
