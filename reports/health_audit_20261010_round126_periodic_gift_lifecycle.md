# 第126轮｜连续周期礼包激活、每日履约与邮件反馈

扫描日期：2026-10-10。问题编号：A242、A243、A244。

## A242｜周期礼包扣费成功但订阅或首日邮件缺失

### 出现什么现象

周期礼包扣费和限购成功后，订阅或首日邮件可能没有创建完整。

### 初步定位

购买通过可吞异常的事件监听履约；订阅先扣首日天数并标已派发再发信，失败后部分状态仍随购买提交。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `shop_service.py` | PERIODIC_GIFT_BUY |
| `periodic_gift_service.py` | 订阅与首日派信 |
| `event_bus.py` | 异常处理 |

## A243｜周期礼包补发后进度保存失败，重试重复寄出邮件

### 出现什么现象

周期礼包每日补发中途失败后，重试会重复发送已发邮件。

### 初步定位

服务先逐封发信，再统一更新剩余天数和派发日期；缺少订阅与游戏日的唯一发信记录，末尾更新失败会保留旧进度。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `periodic_gift_service.py` | check_and_dispatch_daily |
| `core.py` | 事务前时间pulse |

## A244｜周期礼包次日邮件已生成，在线未读和红点未刷新

### 出现什么现象

周期礼包次日邮件已入库，在线却没有新邮件红点推送。

### 初步定位

每日派发只写SQL，没有生成30001通知；购买首日另有主动推送，因此首日正常而在线补发缺失。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `periodic_gift_service.py` | 每日派信 |
| `mail_service.py` | send_mail |
| `shop_service.py` | 首日30001 |
