# 第96轮｜登录成就周期与旧状态补帧

扫描日期：2026-10-08。问题编号：A142、A143。

## A142｜登录补发旧状态，成就和冷却剂进度被覆盖

### 出现什么现象

同日重复签到时，客户端材料数量和成就进度可能被旧数据覆盖。

### 初步定位

动态回复没有新增某类状态帧时，Core按协议号补入 skeleton 中的历史17023、53003，固定数量14和进度251覆盖当前展示。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `core.py` | 11010骨架补帧 |
| `skeleton.json` | 17023、53003 |
| `operations.py` | 同日签到回复 |

## A143｜成就按零点计日，签到按五点计日，同一天累计口径不同

### 出现什么现象

凌晨登录时，成就登录天数和签到累计天数在不同时间变化。

### 初步定位

成就按自然日零点去重，任务及签到按05:00换日；同一登录事件被两套日界线消费。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `achievement_service.py` | 登录日期判断 |
| `task_listener.py` | 05:00周期 |
| `generator.py` | 签到日判断 |
