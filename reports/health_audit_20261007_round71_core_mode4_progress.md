# 第71轮｜Mode 4队伍成绩恢复与任务达标

扫描日期：2026-10-07。问题编号：A94、A95。

## A94｜Mode4 恢复遗漏队伍和挑战关，第二队编号也会丢失

### 出现什么现象

Mode4 恢复包缺挑战关和出战队伍，第二队编号也没有保留下来。

### 初步定位

构造器只选普通关且把锁定队伍固定为空；第二队信息在请求解析与会话保存时丢失，已有成绩和阵容未完整进入回复。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `weekly_challenge_service.py` | Mode4 89801 构造 |
| `middleware.py` | 出战队伍解析与会话登记 |
| `account_db.py` | 挑战进度读取 |

## A95｜Mode4 任务通关后仍不显示可领奖

### 出现什么现象

Mode4 任务已经通关，界面仍显示进行中，不能正常点领奖。

### 初步定位

构造器只遍历领取记录生成 state=2，没有根据通关条件生成 state=1；未领任务达标后也不出现在列表。

### 相关文件与入口

| 文件 | 定位入口 |
| --- | --- |
| `weekly_challenge_service.py` | finish_assignment_list 构造 |
| `CoreVerificationRewardView.lua` | 任务状态读取 |
